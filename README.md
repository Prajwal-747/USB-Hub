# USB Hub V2

This is a compact custom USB hub designed by Prajwal.  
This project focuses on creating a clean, functional, and manufacturable USB hub board with proper port spacing, PCB layout optimization, and compact form factor design.

---

## Features

- Multiple USB ports in a compact layout
- Custom PCB designed in EasyEDA
- Optimized trace routing
- Compact form factor for desk/workbench use
- Silkscreen branding and versioning
- Designed for future enclosure/CAD integration

## Design Goals

The goals of this project are:

- Learn PCB design and hardware development
